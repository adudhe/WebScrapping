# Python Web Data Extraction

## Overview

This project demonstrates automated web data extraction using Python to collect, transform, and analyze publicly available web data.

## Objective

The goal was to automate the collection of structured information from websites and export the results into a format suitable for downstream analytics and reporting.

## Technologies Used

* Python
* BeautifulSoup
* Requests
* Pandas
* OpenPyXL

## Workflow

1. Connect to target website
2. Extract relevant data fields
3. Clean and transform raw data
4. Export results to Excel
5. Prepare dataset for analysis

## Repository Contents

* `Main.py` – Primary extraction workflow
* `SonarakScript.py` – Supporting scraping logic
* `solarkal_data.xlsx` – Sample extracted dataset

## Key Learnings

* HTML parsing and navigation
* Automated data collection
* Data cleansing and transformation
* Exporting structured datasets for analytics
